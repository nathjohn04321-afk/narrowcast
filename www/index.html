These four leave the app. They are tied to your Google account, so they can only open in YouTube — nothing else here does. The YouTube home page is the one place where the algorithm outranks you, and it is deliberately missing.

YouTube connection

Without a key the app still works, it just hands searches and channels to YouTube instead of showing them here. A key is free: make a project at console.cloud.google.com, enable YouTube Data API v3, then create an API key under Credentials. The free allowance is 10,000 units a day, which is about 90 searches; opening a channel costs 2.

Your data

Everything lives on this phone only.

Clearing your browser’s site data wipes this app. Keep a backup somewhere. The backup file also carries your YouTube key, so it restores onto a new phone in one go — treat the file as private.
